# 福音對話教練

幫助自己更好地跟人聊天、建立關係並傳福音的個人訓練工具。核心是一個學習循環：

**準備 → 實際對話 → 覆盤 → 針對性練習 → 累積經驗 → 下一次準備**

| 頁面 | 用途 |
| --- | --- |
| 準備 | 選對方的門、階段、關係，得到開場建議、可能遇到的問題、自己過去學到的功課 |
| 覆盤 | 聊完回想對話經過、自我檢核，一鍵複製 AI 覆盤指令（貼到 Claude 或 ChatGPT） |
| 練習 | 三種模式：觀摩示範（AI 寫整段示範對話）、AI 傳福音給我（我扮演對方）、我來傳（AI 扮演對方）。可用預設角色或自己的覆盤紀錄 |
| 筆記 | 學到的功課、關心的人與階段變化、代禱清單、匯出／匯入備份 |
| 指南 | 核心內容：三個維度、開場白、問題解碼、16 張解碼卡、福音表述 |

## 使用

手機版：https://hsinchichang.github.io/gospel_coach/ （用 Safari 打開後「加入主畫面」）

本機開發：

```bash
python3 -m http.server 8765
```

然後打開 http://localhost:8765

## 檔案

- `data/content.js`：核心內容（來自「傳福音對話指南 v0.1」）。修改後建議請牧者審閱。
- `data/verses.js`：和合本經文，由 `scripts/fetch_verses.py` 從信望愛聖經網產生。新增經文時，把引用加進腳本的 `REFS` 再執行：
  `python3 -I scripts/fetch_verses.py data/verses.js`
- `js/prompts.js`：AI 覆盤與角色扮演指令。
- `js/store.js`：資料只存在瀏覽器的 localStorage，不會上傳。
- `sw.js`：離線快取。修改檔案後記得把 `CACHE` 版本號加一。

## 內容可信度

1. 核心內容（指南、解碼卡、經文原文）

3. 實戰筆記（個人觀察）
